# Module 10 Courseware: Capstone End-to-End Modernization

## Tier
Optional or Stretch for MVP

## Learning Objectives

- Execute a full modernization flow as a coordinated team.
- Demonstrate planning, coding, deployment, and operational validation.
- Produce a delivery narrative and lessons learned.

## Narrative

The capstone is a synthesis module. In MVP phase one, it should be used only when the core six modules run cleanly with no unresolved provisioning issues.

## Supporting Assets

- Combined artifacts from modules 1, 3, 4, 6, 7, and 8
- Optional artifacts from modules 2, 5, and 9

## Lab Alignment

- Matching lab: `mvp-delivery/labs/lab-10-capstone-end-to-end.md`
- Required output: end-to-end demo package and retrospective notes

## Success Criteria

- Team demonstrates a traceable, tested, deployed modernization increment.
