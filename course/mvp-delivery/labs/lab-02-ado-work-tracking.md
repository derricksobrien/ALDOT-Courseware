# Lab 02: ADO Work Tracking

## Module
Module 02 - Azure DevOps Work Tracking

## Tier
Optional MVP Lab

## Goal
Create the modernization board, backlog, and sprint traceability.

## Prerequisites

- ADO organization/project access
- Team members assigned

## Steps

1. Create epics and features aligned to modernization goals.
2. Add user stories, tasks, and bugs.
3. Plan one sprint with capacity.
4. Create dashboard queries and status widgets.
5. Link work items to commits or pull requests.

## Validation

- Board hierarchy is complete.
- Queries and dashboard render live data.

## Evidence

- Board screenshots
- Query export or screenshots
