# Lab 09: Azure Deployment and Operations

## Module
Module 09 - Azure Deployment and Operations

## Tier
Optional MVP Lab

## Goal
Deploy to Azure and establish baseline observability.

## Prerequisites

- Azure subscription and quota
- Deployment templates ready
- App artifact available

## Steps

1. Deploy core resources from templates.
2. Deploy app artifact.
3. Configure identity and secret access.
4. Enable logs, metrics, and alerts.
5. Validate app and telemetry behavior.

## Validation

- Deployment succeeds without manual rework.
- Monitoring and alerts show active signals.

## Evidence

- Deployment output
- Dashboard screenshots
- Alert rule proof
