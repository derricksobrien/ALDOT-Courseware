# Lab 02: Azure DevOps Work Tracking

## Module Alignment
Module 2: Azure DevOps (ADO) Work Item Tracking

## Timebox
60 minutes

## Objectives
- Stand up a modernization project board.
- Model epics, features, user stories, tasks, and bugs.
- Build sprint metrics and dashboard widgets.

## Prerequisites
- Azure DevOps project access.
- Team members assigned to the project.

## Step-by-Step
1. Create a new team and area path for modernization.
2. Add 2 epics (Platform Modernization and Delivery Automation).
3. Add at least 4 features under those epics.
4. Add at least 12 user stories and break each into tasks.
5. Configure one sprint and plan capacity.
6. Create queries for blocked work, bugs by severity, and sprint burndown.
7. Create a dashboard with velocity, burndown, and open defects.
8. Link at least 3 work items to Git commits or pull requests.

## Validation Checks
- Work hierarchy is complete and linked.
- Dashboard widgets show live data.
- Sprint backlog has estimated tasks and owners.

## Deliverables
- Project board screenshot set.
- Exported query definitions.
- Sprint planning summary.

## Stretch Goals
- Add policy automation for required work-item linking in pull requests.
