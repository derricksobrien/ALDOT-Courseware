# Lab 05: Test Automation and Quality Gates

## Module Alignment
Module 5: Test Automation with Tricentis Tosca

## Timebox
75 minutes

## Objectives
- Build model-based test assets for UI and API paths.
- Execute tests and publish outcomes to planning tools.
- Define quality gates for release readiness.

## Prerequisites
- Tricentis Tosca access.
- Running test target from Labs 3 and 4.
- If Tosca is not installed or licensed for the cohort, treat this lab as an instructor-led demo and focus on the test design artifacts.

## Step-by-Step
1. Scan the web UI and create reusable Tosca modules.
2. Build 5 UI test cases including one negative path.
3. Build 5 API test cases against the new REST endpoint.
4. Organize tests into execution lists for smoke and regression.
5. Execute tests and capture reports.
6. Integrate results with Azure DevOps or GitHub workflow reporting.
7. Define release gate thresholds for pass rate and defect severity.

## Validation Checks
- At least 10 automated test cases execute successfully.
- Results are visible in pipeline or test reporting dashboard.
- Quality gate definition is documented.

## Deliverables
- Tosca workspace export.
- Test execution report.
- Quality gate checklist.

## Stretch Goals
- Add data-driven variations and risk-based test tagging.
