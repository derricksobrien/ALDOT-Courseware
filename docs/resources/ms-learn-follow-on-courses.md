# Microsoft Learn — Follow-On Courses by Module

**Purpose:** After completing each course module, use these Microsoft Learn paths to go deeper.  
All paths are free, self-paced, and include hands-on sandbox exercises where noted.  
**Created:** 2026-08-11  
**Audience:** Students who want to extend their skills beyond the 10-lab course.

---

## How to Use This Table

1. Find the module you just completed in the left column.
2. Pick one or more MS Learn paths from the right column that match your interest area.
3. Click the link — all paths open directly on Microsoft Learn.
4. Look for the **sandbox icon** 🧪 next to paths that include free Azure sandbox exercises (no subscription needed).
