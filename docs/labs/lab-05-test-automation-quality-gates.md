# Lab 05: Test Automation and Quality Gates

## Module
Module 05 - Test Automation with Tosca

## Tier
Optional MVP Lab

## Goal
Build and run automation suites and define release quality gates.

## Prerequisites

- Target app from Lab 04
- Tosca installed and licensed
- Use the Tosca tenant URL and instructor credentials from `tosca-secrets.md`
- If Tosca is unavailable for the cohort, treat this as an instructor-led demo and keep the test design artifacts.

## Steps

1. Sign in to the Tosca cloud tenant and confirm the workspace opens.
2. Scan the Lab 04 UI and API surfaces and create reusable test modules.
3. Build smoke and regression suites with a mix of positive and negative paths.
4. Execute test lists and capture results.
5. Publish results to pipeline or work tracking.
6. Define pass/fail quality gate thresholds.

## Validation

- Automated suite executes successfully or a complete instructor demo is captured.
- Quality gate criteria are documented.

## Evidence

- Execution run report
- Published result screenshot
- Gate policy checklist
